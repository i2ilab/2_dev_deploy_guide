# 小智 / Reading Bot —— 架构与部署(🟢 入门档)

> **看颗粒度,别照抄。** 小智是一只陪凉山孩子学汉语的猫头鹰学伴。技术上它是"入门档"的好范本:**大部分是静态网页,AI 只是锦上添花,连不上也不影响用**。这套思路特别适合"先上线、给人看得见"。

## 一句话架构
**纯前端静态页(能离线)+ 一个很薄的 AI 陪伴后端 + 优雅降级兜底。**

## 前端:Next.js 静态导出(= 一堆 HTML/JS,能塞进 APK)
- 用 Next.js,但开了 `output: "export"`(`next.config.ts`)——意思是**构建出来就是一堆纯静态文件**(HTML/CSS/JS),不需要一直开着服务器,甚至能打包进安卓 APK 离线跑。
- 游戏内容(认字关卡)是**写死在代码里的 TypeScript 数据文件**(`src/data/stage{1-4}/…`),不连数据库——版本发布时内容跟着走,简单可靠。
- 白话:**"静态"= 页面提前做好了,谁访问都是同一份,便宜又快。** 你的展示页、作品集,都该走这条路(GitHub Pages 就够)。

## 后端:一个很薄的陪伴服务(companion agent)
- 一个**零依赖的 Node 小服务**(`server.mjs`,约 70 行)负责把静态文件发出去,并转发 `/api/companion` 给陪伴逻辑。
- 陪伴 agent(小智本体)支持三种模型后端(API key / 订阅 token / CLI),**key 都在后端**,前端只发"脱敏后的上下文"(掌握了哪些词、心情如何),**从不发孩子真实姓名**。
- 白话:后端就是"替前端保管 key、替前端说话"的中间人——和你在本模块端到端示例里写的 FastAPI 是同一个角色。

## ★ 最亮的一招:优雅降级(CompositeProvider)
- 文件:`src/lib/companion/composite-provider.ts`(约 31 行)。
- 逻辑:**先试真 LLM → 超时或失败 → 悄悄回退到预设脚本**,孩子完全感觉不到"AI 挂了"。
- 为什么重要:真实产品里网络会断、额度会用光。**AI 不可用时,产品不能崩在用户脸上**——尤其面对孩子/脆弱人群。
- **你能直接用**:本模块端到端示例的前端 `catch` 兜底(连不上后端就给一句安抚 + 热线)、后端的 `FALLBACK`,就是这一招的最小版。抄这个思想,别让你的 demo 白屏。

## 记忆与隐私(顺带学:红黄绿落地)
- 三种记忆存**浏览器本地(IndexedDB)**:情景(这次玩了啥)/ 语义(掌握了哪些词)/ 程序(有效的教学策略)。
- key 用**化名**(如"星星3班-07"),绝不存真名——这就是 1_DEFINE 讲的"红黄绿数据分级"在代码里的样子:真实身份是"红",禁止采集。

## 部署
- **Railway**:`railway.json` 里 `npm run build`(导出静态)+ `node server.mjs` 启动 + `/api/health` 健康检查。
- 还能打包成**安卓 APK**(Capacitor)或塞进学习机 WebView——因为前端是纯静态的,离线也能跑。

## 给你的三条可迁移经验
1. **能静态就静态**:展示页/作品集走 GitHub Pages,免费又稳。
2. **优雅降级是标配**:AI 调不通要有兜底话术,不能白屏、不能报错给用户看。
3. **隐私前置**:只上传脱敏信息,真实身份用化名——数据先过"红黄绿"再动。
