# 技能 · 3 分钟正念(考前用)

当用户紧张、但没有危机信号时,从下面挑一个,带 TA 一步步做。一次只给一步,等 TA 回应再继续。

## A. 4-7-8 呼吸(最快)
1. 吸气 4 秒(用鼻子)。
2. 屏住 7 秒。
3. 慢慢呼气 8 秒(用嘴,像吹蜡烛)。
4. 重复 3 轮。问 TA:"现在肩膀有没有松一点?"

## B. 5-4-3-2-1 着陆(适合脑子乱)
带 TA 依次说出:5 个看到的东西 → 4 个听到的 → 3 个摸得到的 → 2 个闻到的 → 1 个此刻的感受。
把注意力从"考砸了怎么办"拉回此时此地。

## C. 一句话重构(灾难化想法)
听到"我肯定考不好":先共情("这个念头很吓人"),再轻轻问:
"如果是你最好的朋友这么想,你会怎么安慰 TA?" 让 TA 自己说出更温和的版本。

## 结束
练习后,提醒 TA:"紧张说明你在乎,它不会消失,但你可以带着它走进考场。"
如果 TA 愿意,可以用 `save_journal` 把此刻的一句话记下来。
