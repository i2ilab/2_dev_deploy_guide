# web 术语速查表(贴墙版)

> **不用背,查着用。** 看到 Claude Code 蹦出一个陌生词、报错里冒出一个术语——回这张表扫一眼,就不慌了。
> 「例子」尽量锚定你的运行示例 `example_project/端到端示例_考前3分钟/`(前端 `frontend/index.html`、后端 `backend/main.py`)。
> 定位:**看懂 + 会指挥**。你不用会手写,认得它"其实是什么"就够。

---

## 一、前端三件套(网页由什么组成)

| 术语 | 一句白话 | 例子(锚运行示例) | 看到它别慌 |
|---|---|---|---|
| **HTML** | 网页的骨架/结构 | `index.html` 里的 `<header>`、`<form>` | 就是"内容放哪"的说明书 |
| **标签 tag** | 用尖括号包住内容的记号 | `<button>发送</button>` | 一对 `<x>…</x>`,包住一块东西 |
| **元素 element** | 一个完整的标签盒子 | 整个 `<input>` 输入框 | 就是页面上一个"零件" |
| **属性 attribute** | 给标签加的设定 | `placeholder="说说"`、`id`、`class` | 给零件贴的小标签/参数 |
| **CSS** | 网页的样式/外观 | 按钮的橙色、圆角 | 负责"好不好看",不管内容 |
| **选择器 selector** | 选中要化妆的元素 | `.btn { … }` 选所有 class=btn | "先选谁,再化妆" |
| **盒模型 box model** | 每个元素=内容+内边距+边框+外边距 | 按钮的 `padding: 10px` | 元素周围的"留白规则" |
| **flex / 布局** | 让元素自动排队对齐 | 聊天气泡左右排列 | "怎么摆放"的排版方式 |
| **JavaScript(JS)** | 让网页"动"起来的行为 | 点发送→调后端→显示回复 | 网页的"电路/大脑" |
| **变量 variable** | 存东西的盒子 | `const history = []`(聊天记录) | 起个名字存一个值 |
| **函数 function** | 一段可反复调用的动作 | `sendMsg(text)` | "做某件事"的按钮 |
| **事件 event** | 用户操作触发动作 | `onclick`、`onsubmit` | "当用户点/提交时,就…" |
| **DOM** | JS 眼里的网页(可增删改) | JS 往页面加一个气泡 | 网页的"可编辑版" |

## 二、数据与 API(前后端怎么对话)

| 术语 | 一句白话 | 例子(锚运行示例) | 看到它别慌 |
|---|---|---|---|
| **JSON** | 前后端通用的"普通话"数据格式 | `{"messages":[…]}` | 就是"键: 值"清单,大括号包着 |
| **fetch** | 前端向后端"打电话" | `fetch(BACKEND+"/api/chat")` | "网页去后端要东西" |
| **API** | 后端对外开放的"菜单" | 后端开了 `/api/chat`、`/api/health` | 一组"能点的服务" |
| **端点 endpoint** | 菜单上的一道菜(一个地址) | `/api/chat` | 一个具体的服务网址 |
| **REST** | 大家都遵守的点单规矩 | 用 URL + GET/POST 表达意图 | 一种"约定俗成"的 API 风格 |
| **GET** | 取数据(不改东西) | `GET /api/health` 体检 | "读一下" |
| **POST** | 提交数据(会做事) | `POST /api/chat` 发消息 | "交上去,让它办" |
| **请求/响应 request/response** | 一问一答 | 前端问、后端答 | 打电话:你说一句、对方回一句 |
| **状态码 200** | 成功 | 正常拿到回复 | 绿灯,没事 |
| **状态码 400/401** | 你发的请求有问题 | 参数错 / 没权限(key 错) | "你这边填错了" |
| **状态码 404** | 找不到 | 地址/端点写错了 | "这个网址不存在" |
| **状态码 500** | 后端自己崩了 | 服务器内部报错 | "对方那边出事了,去看后端日志" |

## 三、前端框架(复杂界面才需要)

| 术语 | 一句白话 | 例子(锚运行示例) | 看到它别慌 |
|---|---|---|---|
| **框架 framework** | 给复杂项目用的"工具箱" | 简单页用不上,一个 `index.html` 就够 | "轮子",别自己造 |
| **React** | 最主流的前端库,组件化 | Agent Leo、小智都用它 | 把界面拆成可复用积木 |
| **组件 component** | 一块可复用的界面 | 一个"消息气泡"写一次到处用 | 界面的"乐高积木" |
| **props** | 传给组件的参数 | 同一个气泡传不同文字 | "给积木喂不同内容" |
| **state** | 组件的"记忆",变了自动重画 | 输入框里的字、聊天历史 | 组件"记住"的东西 |
| **Next.js** | React 的"全能框架" | Agent Leo(Next 14)、小智(Next 静态导出) | React + 路由 + 后端一体 |
| **SSR 服务端渲染** | 服务器先把页面画好再发 | 首屏更快、更利于搜索 | "后端先渲染好" |
| **静态 vs 动态** | 发好的文件 vs 现场生成 | 展示页(静态)/ 能对话(动态) | 决定你要不要后端 |

## 四、后端与服务器(藏 key、干重活)

| 术语 | 一句白话 | 例子(锚运行示例) | 看到它别慌 |
|---|---|---|---|
| **server(服务器)** | 一直开机、接电话的程序/机器 | 你的 FastAPI 后端 | "远处那台一直在线的电脑" |
| **Node.js** | 用 JavaScript 写后端 | Next.js/Vercel 的原生路线 | "后端也用 JS" |
| **Python 后端** | 用 Python 写后端 | 你在 0_agent_basic 会的 Python | 你的默认、心智不用切 |
| **FastAPI** | 最短路径把 Python 变 API | `backend/main.py` | 几行就开一个 API |
| **uvicorn** | 把 FastAPI 跑起来的"发动机" | `uvicorn main:app --port 8000` | "启动后端"的命令 |
| **`@app.post(...)`** | 开一道菜(定义端点) | `@app.post("/api/chat")` | "注册一个接口" |
| **数据库 / Supabase** | 长期存很多数据的地方 | Agent Leo 用 Supabase 存账号 | 简单项目先不用,存文件就够 |

## 五、工程工具链(你要认得的环境)

| 术语 | 一句白话 | 例子(锚运行示例) | 看到它别慌 |
|---|---|---|---|
| **终端 Terminal** | 打字给电脑下命令的黑框 | 跑 `uvicorn`、`npm` 的地方 | "命令行",不是黑客,是下指令 |
| **localhost** | 你自己这台电脑(本地) | `http://localhost:8000` | "本机地址",只有你看得到 |
| **端口 port** | 电脑上的"门牌号" | 后端 :8000、前端 :5500 | 区分同一台机上不同服务 |
| **环境变量 env** | 存在系统里的秘密/配置 | `OPENROUTER_API_KEY` | key 放这里,不写进代码 |
| **`.env`** | 本地存 env 的文件(不上传) | `cp .env.example .env` | 被 `.gitignore` 挡住,绝不进 git |
| **CORS** | 浏览器的跨域安全规矩 | 后端要允许前端域名 | 报 CORS 错=后端没放行前端 |
| **npm** | JS 的包管理器(装轮子) | `npm run dev` | "装 JS 依赖"的工具 |
| **pip** | Python 的包管理器 | `pip install -r requirements.txt` | "装 Python 依赖" |
| **requirements.txt** | Python 依赖清单 | fastapi / uvicorn / httpx | "这个项目要装哪些库" |
| **git / GitHub** | 代码存档 + 云端仓库 | `git push` 上去才能部署 | "代码的云盘 + 时光机" |
| **DevTools(F12)** | 浏览器自带的排错透视镜 | Console 看报错、Network 看请求 | 排错神器,按 F12 打开 |
| **Console 控制台** | 看 JS 报错的地方 | 红字报错先截图 | "前端的报错在这看" |
| **Network 网络面板** | 看每个请求成没成 | 看 `/api/chat` 是 200 还是 404 | "请求体检表" |

## 六、部署(送上线)

| 术语 | 一句白话 | 例子(锚运行示例) | 看到它别慌 |
|---|---|---|---|
| **HTTP / HTTPS** | 网页传输协议(S=加密) | 所有网址前缀 | 现在都用 https |
| **域名 domain** | 人好记的网址 | `yourname.github.io` | 网站的"门牌" |
| **DNS** | 把域名翻译成机器 IP | 输网址后第一步 | "网络的通讯录" |
| **GitHub Pages** | 免费托管静态前端 | 放你的 `index.html` | 静态展示页首选,免费 |
| **Railway** | 托管 Python 后端(默认) | 跑你的 FastAPI | 自动识别 Python,= HEAI 同款 |
| **Vercel** | 免费替代(偏 Node/前端) | 静态或 Node serverless | 免费额度大,Python 稍麻烦 |
| **key / API key** | 调模型的"密码" | `OPENROUTER_API_KEY` | **只能在后端**,前端泄漏=账单爆炸 |
