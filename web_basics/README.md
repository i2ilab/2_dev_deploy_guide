# web_basics — AI 时代 web 技术栈基础

> `2_dev_deploy_guide` 教你用 Claude Code 把 PRD 做成前端+后端并上线。但如果你从没写过网页,会遇到一个尴尬:**AI 帮你写了一堆代码,你却看不懂它写了什么、报错时不知道哪儿坏了。**
> 这个前置基础包补上这块地基——**不是教你手写代码,是教你「看懂 + 会指挥」**:读得懂 Claude Code 写的东西、知道每一层是什么、报错时救得回来。
> **你不需要成为程序员。你需要的是:能有效指挥 AI,并在它出错时接得住。**

---

## 为什么零基础也要懂一点 web

2026 年,约 **90% 的开发者每天用 AI 编程工具**(Claude Code / Cursor / v0 / bolt / Lovable)。工作流已经变了:**AI 生成代码,你审阅 + 指挥**。所以对你这样的心理/教育背景学生,「看懂」比「会手写」重要得多:

| | 没有这块地基 | 有了这块地基 |
|---|---|---|
| **看懂** | AI 写的文件像天书 | 知道每个文件、每层大概是干嘛的 |
| **会指挥** | 只会说"帮我做个网站" | 能说清"改后端 /api/chat"还是"改前端样式" |
| **能排错** | 白屏/报错就抓瞎 | 看懂 404/500/CORS,说清哪层错,AI 才修得快 |

## 怎么用

- **最好的活教材是你手边的运行示例**:`../example_project/端到端示例_考前3分钟/frontend/index.html`(前端三件套都在这一个文件里)+ `backend/main.py`(FastAPI 后端)。教程里每个概念都回指它。
- **零基础**:先读主教程(约 1 小时)或过一遍 slides,再回 `2_dev_deploy_guide` 的 **B1–B4** 动手。
- **有点基础**:直接查速查表和 resources,遇到陌生词回来查。

## 和 Build/Ship 的衔接

这是 `2_dev_deploy_guide` 的**前置软依赖**(有 web 基础可跳过)。读完你就能真正看懂:
- **B2 后端服务化** 里的 FastAPI `/api/chat` 是什么
- **B3 前端界面** 里 Claude Code 生成的 HTML/JS 在做什么
- **B4 连通与安全自检** 里的 CORS、`grep sk-`、"前端是公开的"为什么重要
