# 前端提示词卡（配合 BUILD/B3）

> **怎么用**:把下面这段填好,一次性发给 Claude Code,它就能生成你的聊天页。【】替换成你的项目。

## 三句话主提示词
```
帮我做一个单页聊天界面(纯 HTML，不用框架)：
1. 做什么页：历史消息在上、输入框在下的聊天页。
2. 什么风格：【温暖 / 圆角 / 马卡龙暖色】——贴合我的【正念陪伴】项目。
3. 连哪个后端：把 messages 数组 POST 到 /api/chat，回复显示成气泡。
   本地连 http://localhost:8000，线上连 https://【我的后端】.up.railway.app。
```

## 追加要求（务必带上）
```
- 右上角加一个醒目的「【我需要紧急帮助】」按钮，点了就发一条求助消息。
- 后端连不上时不要白屏：显示一句安抚话 +（全国心理援助 12356 / 120）。
- 整个页面里【绝对不要】出现任何 API key，只调用后端接口。
```

## 你的自检（生成后自己做）
- [ ] 本地能和后端一来一回对话
- [ ] 危机按钮能触发转介
- [ ] 关掉后端 → 页面不白屏,有兜底
- [ ] `grep -rniE "sk-[a-z0-9]{16}" .` → **为零**
