# 密钥与环境变量清单

> **怎么用**:配合 `SHIP/S2`。把你项目所有的"秘密"和"配置"列清楚——放哪、是否进 git。原则:**秘密只进平台 Variables,绝不进代码/前端/git。**

## 1. 环境变量登记表

| 变量名 | 是什么 | 放哪(平台 Variables) | 进 git 吗 | 进前端吗 |
|---|---|---|---|---|
| `OPENROUTER_API_KEY` | 模型调用密钥 | 【Railway / Vercel】 | ❌ 绝不 | ❌ 绝不 |
| `MODEL` | 用哪个模型(可选) | 【Railway】 | ❌(用 .env.example 占位) | ❌ |
| `CORS_ORIGINS` | 允许的前端域名 | 【Railway】 | ❌ | ❌ |
| 【其它,如数据库 URL】 | 【】 | 【】 | ❌ | ❌ |

## 2. 本地怎么配

- 复制 `.env.example` → `.env`,把真值填进 `.env`。
- **`.env` 必须在 `.gitignore` 里。**

## 3. `.gitignore` 必含

```
.env
.env.*
__pycache__/
*.pyc
.DS_Store
```

## 4. 上线前自检(勾选)

- [ ] 前端目录 `grep -rniE "sk-[a-z0-9]{16}"` = 零
- [ ] `.env` 在 `.gitignore`,没被提交
- [ ] `git log -p | grep sk-` 无结果(历史里也没泄露过)
- [ ] 所有秘密都只在平台 Variables 里
- [ ] `.env.example` 里是占位符,不是真 key
