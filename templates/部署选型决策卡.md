# 部署选型决策卡

> **怎么用**:配合 `SHIP/S0`。先回答"静态还是动态",再照着选平台。把【】填成你的项目。

## 1. 静态还是动态?

- 我的项目要**实时调模型对话**吗?　【是 / 否】
  - 否 → 只有展示页 → **纯静态**(只需 GitHub Pages)
  - 是 → **混合**(前端静态 Pages + 后端动态 Railway/Vercel)

## 2. 选平台

| 部分 | 我选 | 平台 | 免费吗 | key 放哪 |
|---|---|---|---|---|
| 前端(静态页) | 【GitHub Pages】 | Pages | ✅ 免费 | 无 key |
| 后端(FastAPI) | 【Railway / Vercel】 | 【】 | Railway ~$5;Vercel 免费 | 平台 Variables |
| 国内长期服务? | 【否 / 腾讯云】 | 【】 | 需实名+费用 | 平台 env |

## 3. 我的最终路线(一句话)

> 前端 `index.html` → 【GitHub Pages】;后端 FastAPI(包 harness)→ 【Railway】;
> key `OPENROUTER_API_KEY` 放在【Railway Variables】;`CORS_ORIGINS` = 【我的 Pages 域名】。

## 4. 成本与风险自问

- [ ] 我知道 Railway 非永久免费,能接受 / 或改用 Vercel 免费
- [ ] 我知道 key 绝不进前端、不进 git
- [ ] 我知道国内访问可能不稳(课堂够用)
