# 结项技术文档(技术架构章)

> **怎么用**:配合 `SHIP/S4`,对齐 `2_hcai_guide` T8「项目文档六要素」第 4 节。这是结项三件套(文档 + 云端原型 + 展示 PPT)里的"技术架构"部分。把【】填成你的项目。

## 1. 架构图(照着画你的)

```
  用户(手机/电脑浏览器)
        │ HTTPS
        ▼
  前端【index.html,静态】 ──POST /api/chat──►  后端【FastAPI,包 mini CC harness】
  部署:【GitHub Pages】                        │  安全:危机确定性拦截 + 子agent复核 + 优雅降级
  无 key                                        ▼
                                          模型【OpenRouter,key 在后端 env】
                                          部署:【Railway】
```

## 2. 技术选型与理由

| 部分 | 我用了 | 为什么 |
|---|---|---|
| 前端 | 【静态 HTML / 其它】 | 【零构建、Claude Code 生成、Pages 免费】 |
| 后端 | 【FastAPI 包 harness】 | 【复用模块1造的 mini CC harness,Python 顺手】 |
| 部署 | 【Pages + Railway】 | 【Railway 自动识别 Python;= HEAI 同款】 |
| 模型 | 【haiku / 其它】 | 【低延迟够用 / 成本】 |

## 3. 安全设计(必写)

- key 走后端 env,前端零 key:【】
- 危机护栏:【is_crisis 确定性拦截 + 危机转介 skill 置顶】
- 安全复核:【c3 式子 agent 独立审 / 说明】
- 优雅降级:【模型失败给兜底,不白屏】

## 4. 复现步骤(别人怎么跑起来)

```
1. 装依赖:【pip install -r requirements.txt】
2. 配 env:【复制 .env.example → .env,填 OPENROUTER_API_KEY】
3. 起后端:【uvicorn main:app --port 8000】
4. 开前端:【打开 index.html / python -m http.server】
```
