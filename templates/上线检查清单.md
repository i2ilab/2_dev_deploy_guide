# 上线检查清单

> **怎么用**:配合 `SHIP/S4`。把网址发给真实用户**之前**,逐条勾。任一"密钥安全"或"危机护栏"不过 = **不许上线**(一票否决)。

## 1. 🔑 密钥安全(一票否决)
- [ ] 前端目录 `grep -rniE "sk-[a-z0-9]{16}"` = 零
- [ ] key 只在平台 Variables(Railway/Vercel)
- [ ] `.env` 在 `.gitignore`,未提交
- [ ] `git log -p | grep sk-` 无结果

## 2. ✅ 可用性
- [ ] 公网 URL 能打开
- [ ] 完整对话一轮正常
- [ ] **手机上**打开、能用(很多用户是手机)
- [ ] 换一个没参与的人也能用

## 3. 🛟 内容合规与安全(一票否决:危机护栏)
- [ ] 界面明示"我是 AI,不能替代专业帮助"
- [ ] 一句话隐私说明(不采集真实身份 / 数据用途)
- [ ] **危机热线正确可见**:全国 12356 · 北京 010-82951332 · 紧急 120
- [ ] 危机输入(如"撑不下去了")→ 线上**立刻转介真人**,不自行处理

## 4. 🧯 优雅降级
- [ ] 后端 / 模型失败 → 前端给兜底话术,不白屏、不甩报错栈
- [ ] 兜底话术里也带危机热线

## 5. 📄 README 三要素
- [ ] 是什么(一句话:帮谁在什么场景解决什么)
- [ ] 怎么用(网址 + 一个示例输入)
- [ ] 谁做的(小组成员 + 课程信息)
