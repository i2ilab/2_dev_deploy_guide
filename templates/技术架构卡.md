# 技术架构卡（配合 BUILD/B1）

> **怎么用**:动手前填这张卡,想清楚"我要拼哪三层、用 harness 的哪几根支柱、危机怎么拦"。填完贴给 Claude Code 当施工图。【】里是你要填的。

## 1. 项目一句话
> 我在做一个帮助【谁】在【什么场景】的【什么】agent。（抄你的 T1 选题）

## 2. 选哪档参考架构
- [ ] 轻档（小智式:静态 + 离线兜底）
- [ ] **中档（HEAI 式:静态前端 + FastAPI 后端,默认）**
- [ ] 重档（Leo 式:Next 全栈 + 数据库 + 多 agent）
理由:【为什么这档适合我 / 我的能力和时间】

## 3. 三层
| 层 | 用什么 | key 在这吗 |
|---|---|---|
| 前端 | 【静态 index.html / …】 | ❌ 绝不 |
| 后端 | 【FastAPI /api/chat】 | ✅ 只在这 |
| 模型 | 【OpenRouter · 模型名】 | — |

## 4. 后端用到 harness 的哪几根支柱（勾）
- [ ] c0 JSON 协议（默认要）
- [ ] c1 工具箱 —— 我的领域工具:【save_journal / lookup_scale / …】
- [ ] c2 TodoWrite（多步任务才需要）
- [ ] **c3 子 agent 安全复核（心理/教育强烈建议要）**
- [ ] c4 上下文压缩（长对话才需要）
- [ ] c5 权限门 → 服务端版:白名单工具、【去掉 bash】

## 5. 危机拦截方案（安全一票否决）
- 确定性关键词拦截:【列几个必拦词:自杀/撑不下去/…】
- 触发后动作:【停练习 → 转介真人 → 给热线 12356 / 010-82951332】
- 子 agent 复核:【出稿前审一遍安不安全】
