# 前端安全清单（BUILD 阶段 · key 铁律）

> 前端是**公开**的——任何人右键"查看源代码"都能看到里面所有东西。这张清单就一个核心:**别让 key 出现在前端。**

## 🔑 密钥（一票否决,不过不许上线）
- [ ] 前端目录 `grep -rniE "sk-[a-z0-9]{16}|openrouter.*key|authorization.*bearer"` = **0**
- [ ] 前端**没有直连模型 API**,只调你自己的后端 `/api/chat`
- [ ] 后端地址用的是域名/相对路径,不含任何密钥参数

## 体验与安全
- [ ] 有醒目的「危机求助」按钮
- [ ] 后端连不上时**不白屏**,给安抚话 + 热线（12356 / 120）
- [ ] **手机上打开**能正常对话(很多用户是手机)
- [ ] 页面能看懂它是 AI（不伪装成真人）

## 上线前最后一眼
- [ ] 把 `index.html` 从头到尾扫一遍,确认只有"后端 URL",没有任何 key
- [ ] 若前端也进 git:`git ls-files` 里没有 `.env`、没有密钥文件
