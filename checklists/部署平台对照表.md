# 部署平台对照表

> 一张表看清四个平台怎么选。默认路线:**前端 GitHub Pages + 后端 Railway**;要免费 → 后端换 Vercel;要长期服务国内 → 换腾讯云/阿里云。

| 平台 | 适合 | 免费吗 | 上手难度 | key 怎么放 | 国内访问 | 一句话推荐 |
|---|---|---|---|---|---|---|
| **GitHub Pages** | 静态前端 / 展示页 | ✅ 永久免费 | ⭐ 最简单 | 无 key(前端不放 key) | 一般(可能慢) | **前端首选**,你已在用 GitHub |
| **Railway** | Python 后端(FastAPI) | ⚠️ ~$5 试用/hobby,非永久免费 | ⭐⭐ 自动识别 Python | 平台 Variables | 一般 | **后端默认**,Python 最省心,= 三真实项目 |
| **Vercel** | 前端 + Node serverless 后端 | ✅ 慷慨免费额度 | ⭐⭐ Node 顺、Python 稍烦 | 平台 Environment Variables | 一般 | **要免费**的后端首选(用 Node 函数) |
| **腾讯云 / 阿里云** | 长期给国内用户的前后端 | ❌ 需实名 + 少量费用(可能要 ICP) | ⭐⭐⭐ 较重 | 平台 env | ✅ 稳定快 | **长期服务国内**再上,课堂不必 |

## 怎么选(30 秒决策)

1. 只有展示页,不对话 → **只用 GitHub Pages**。
2. 要对话、想 Python 顺手、能接受 ~$5 → **Pages(前端)+ Railway(后端)**。← 默认
3. 要对话、要**零成本** → **Vercel**(前端 + Node serverless 后端函数)。
4. 要长期给**国内用户**稳定用 → 迁 **腾讯云/阿里云**。

## 共同铁律(四个平台都一样)

- key 只进平台的 Variables / Environment Variables,**绝不进前端、绝不进 git**。
- 前端永远是公开的,只通过后端 `/api/chat` 间接用 key。
- 上线前 `grep -rniE "sk-[a-z0-9]{16}" 前端目录` 必须为零。
