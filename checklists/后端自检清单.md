# 后端自检清单（BUILD 阶段 · 过了才能进 SHIP）

> 在后端目录逐条打勾。任何一条不过,先别急着上线。

## 能跑
- [ ] `pip install -r requirements.txt` 成功
- [ ] `uvicorn main:app --port 8000` 能起来
- [ ] `curl localhost:8000/api/health` 返回 `{"status":"ok"}`
- [ ] `POST /api/chat` 传 messages,能拿到 `reply`

## harness 内核
- [ ] 内核就是模块 1 的 mini CC harness（JSON 工具循环),没另起炉灶
- [ ] 系统提示 = agent.md + 所有 skill(**危机转介置顶**)
- [ ] c3 式安全复核子 agent 在

## 安全（最重要）
- [ ] 代码里 `grep -rniE "sk-[a-z0-9]{16}"` = **0**
- [ ] key 从 `os.environ` 读;`.env` 在 `.gitignore`,`git ls-files | grep .env` 为空
- [ ] 工具是**白名单**,**没有 bash / rm / os.system 之类**
- [ ] 危机输入("我撑不下去了")→ **一定**返回转介话术(确定性拦截,离线也生效)

## 健壮
- [ ] 模型调不通 → 返回 `FALLBACK`,**不 500**
- [ ] 配了 CORS,前端域名能访问
