# B1 · 装配后端 agent —— 给 harness 装上你的专业和红线

> **目标**:以模块 1 的 mini CC harness 为底,按你的 PRD 装上领域 skills + 危机转介 skill,并开启一个"安全复核"子 agent。产出一个**本地能跑、带安全底线**的 agent。
> **前置输入**:B0 读完;PRD(T4)、设计卡(T5)。
> **产出物**:`templates/技术架构卡.md` 填完 + 一个本地能对话的 agent(`agent.md` + `skills/`)。
> **配套 skill**:`/build-backend`｜**样板**:`example_project/端到端示例_考前3分钟/backend/`

## 为什么这一步:不是造新 agent,是"配置"你造过的 harness

你在 `1_claude_code_basic/c5_guard.py` 已经有了一个能用工具、有权限门的 agent 内核。现在把它变成**你的专业 agent**,只需要换三样东西:**人设(agent.md)、技能(skill_*.md)、红线(危机转介)**——这正是 `1_DEFINE` 设计卡里写好的。**代码内核不动,换文件就换专家**(你在 s5/s6 见过这招)。

## 新想法:后端 agent = harness + 你的 skills + 一个复核子 agent

三件事装上去:

1. **人设 `agent.md`**:把设计卡的"身份 / 语气 / 边界"写进去(样板:`backend/agent.md`)。
2. **技能 `skills/skill_*.md`**:每个工作流一个技能文件;**`skill_危机转介.md` 必备,且拼系统提示时置顶**(样板:`backend/skills/`)。
3. **安全复核子 agent(c3)**:主 agent 出稿后,派一个**独立的**子 agent 审"这条回复安不安全、越界没"——这就是 `1_DEFINE` E4 自检环。危机信号还要有**确定性代码**兜底(不只靠模型自觉)。

> 需要更多能力就回模块 1 抄:要 agent 能读写文件/查资料 → `c1_toolbox.py`;长对话怕爆 → `c4_compact.py`。

## 操作步骤(对 Claude Code 说什么 + 你检查什么)

1. **给它设计卡**:把你的 T4/T5 贴给 Claude Code,说:"照这份设计卡,帮我写 `agent.md`(身份/语气/边界)和每个工作流一个 `skill_*.md`。"
   - ✅ 你检查:`agent.md` 里"绝不做"的边界,和你设计卡一致吗?
2. **危机转介必备**:说:"再写一个 `skill_危机转介.md`,列出触发信号 + 真人热线(全国 12356、北京 010-82951332),要求识别到危机就停下、转真人。"
   - ✅ 你检查:热线号码对吗?触发词覆盖隐晦信号("撑不下去""不想醒")吗?
3. **装上 harness**:说:"用我们在 `1_claude_code_basic/c5_guard.py` 的 harness 做内核,系统提示 = agent.md + 所有 skill(危机转介置顶)。"
   - ✅ 你检查:本地 `python` 跑一下,问一句普通的、再问一句危机的,反应对吗?
4. **加安全复核子 agent**:说:"在回复用户前,加一个独立的子 agent 审这条回复安不安全(参照 c3 子 agent);危机信号用关键词代码先拦一道。"
   - ✅ 你检查:输入"我撑不下去了",它**必须**走转介,不能继续聊练习。

## 痛点对比

| 😌 简单·看不出必要 | "我直接写个 prompt 让它当心理助手,不就行了?" |
|---|---|
| 🔥 复杂·痛点凸显 | 没有独立复核 + 确定性危机拦截,模型某次"手滑"顺着危机话题聊下去 → 在最脆弱的人身上就是真实伤害。**安全不能只靠模型自觉,得有代码兜底。** |

## 门禁检查(过了才进 B2)

- [ ] `agent.md` 的边界 = 设计卡的边界
- [ ] `skill_危机转介.md` 存在,热线正确,拼提示时置顶
- [ ] harness 内核就是模块 1 的(没另起炉灶)
- [ ] 有一个 c3 式安全复核子 agent + 确定性危机关键词拦截
- [ ] 本地问危机输入 → 一定走转介
- [ ] `技术架构卡.md` 填完(选了哪档、用了哪几个 harness 支柱)

## 思考题

> 你的 agent 会不会在用户"只想被听见"的时候急着塞练习?
> 把 c3 复核子 agent 想成一个"更冷静的同事"——它不产出内容,只专门问一句:"这样回,安全吗?"
