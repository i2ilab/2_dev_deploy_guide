# B0 · 总览 —— 你是导演,不是码农

> **目标**:建立开发心态——你不亲手写代码,你**指挥 Claude Code 写**,你负责三件事:看懂架构、守住 key 安全、把好危机红线。
> **前置输入**:你在 `1_DEFINE_guide` 产出的 PRD(T4)+ DEFINE 设计卡(T5);你在 `0/1_claude_code_basic` 造过的 agent/harness。
> **产出物**:—(读)。
> **配套 skill**:—。

## 先打个气:零基础也能做出能上线的产品

你可能一行前端都没写过,别慌。今天的开发,姿势和你前几天**指挥 Claude Code 造 agent** 一模一样:你说人话,它写代码,你验收。你真正要懂的,不是语法,而是**这三样东西怎么拼**——以及**哪里绝不能出错**(key、危机)。

## 新想法:一个能上线的 AI 应用,就三层

```
  用户(手机 / 浏览器)
        │  只发消息,拿回复
        ▼
  ①前端  ──调用──►  ②后端  ──调用──►  ③大模型
  一个网页            你的服务器           OpenRouter
  没有 key            key 藏在这里         按量计费
```

- **③模型**:租来的大脑(OpenRouter,你已有 key)。
- **②后端**:你的地盘。**key 只能待在这里。** 它就是——

### 后端地基 = 你在模块 1 造的 mini CC harness

后端**不用从零写**。你在 `1_claude_code_basic` 亲手造的 mini Claude Code(`c5_guard.py`,~39 行)已经是完整内核:JSON 工具循环 + 工具箱 + 子 agent + 压缩 + 权限门。本模块只做一件事:**把它搬上线**(从 `while input()` 变成一个 `/api/chat` 接口)。它的五根支柱,正好对应上线要的五个真实能力:

| harness 支柱(你在模块1造过) | 上线后干什么用 |
|---|---|
| c0 JSON 协议 | 结构化输出,前端好解析 |
| c1 工具箱 | agent 能查量表 / 存情绪日记 / 记录进度 |
| c2 TodoWrite | 多步任务拆步(如带做一次完整 CBT 记录) |
| **c3 子 agent** | **安全复核层**:出稿前让"另一个 agent"审一遍安不安全 —— 这就是 `1_DEFINE` 的 **E4 自检环**落地 |
| c4 上下文压缩 | 长程陪伴多轮不爆 token |
| c5 权限门 | 危险动作要人批准;**服务端版 = 只留白名单工具,去掉 bash** |

- **①前端**:一张脸。用 Claude Code 生成一个聊天网页,**里面绝不放 key**,只调后端。

## 三档参考架构(挑一档抄)

| 档 | 真实项目 | 前端 | 后端 | 适合谁 |
|---|---|---|---|---|
| 轻 | 小智 / reading-bot | 静态页 + **离线兜底** | 轻后端 | 展示为主 / 想要断网也能用 |
| **中(默认)** | **HEAI / renben.ai** | 普通网页 | **Python FastAPI** | **大多数小组**——和你会的 Python 一条链 |
| 重 | Agent Leo / deepsy.ai | Next.js 全栈 | + 数据库 + 多 agent | 想做得像真产品的进阶组 |

本模块默认走**中档**(HEAI 同款):静态前端(GitHub Pages)+ FastAPI 后端(Railway)。可运行样板见 `example_project/端到端示例_考前3分钟/`。

## 思考题

> 如果你把 key 写进了前端网页,会发生什么?(提示:任何人右键"查看源代码"都能看到它。)
