# B2 · 后端服务化 —— 把 harness 变成一个 `/api/chat` 接口

> **目标**:让 Claude Code 把你的 harness 从"命令行里 `input()`"改造成一个**无状态的 Web 接口** `/api/chat`,key 走环境变量,能被前端调用。
> **前置输入**:B1 产出的本地 agent。
> **产出物**:`templates/API契约卡.md` 填完 + 一个本地能调的后端服务。
> **配套 skill**:`/build-backend`｜**样板**:`example_project/端到端示例_考前3分钟/backend/main.py`
> **零 web 基础?** 先花点时间读 `web_basics/`(尤其 W5 API + W7 后端/FastAPI),再回来这一步会顺很多。

## 为什么这一步:命令行跑通 ≠ 别人能用

你的 harness 现在靠 `while True: input()` 在你自己的终端里跑——只有你能用。要让前端网页(将来是手机上的用户)调它,得把它变成一个**服务**:接收一段对话,返回一句回复。这一步不难,**Claude Code 几分钟就能改好**,你要看懂的是它改了哪三个地方。

## 新想法:三处改造(看懂样板 `main.py` 就够)

打开样板 `backend/main.py`,对着看:

1. **`while input()` → `/api/chat` 函数**:前端 POST 一个 `messages` 列表进来,后端跑**一轮** harness(`run_harness`),返回 `{reply, meta}`。**无状态**:历史由前端带着,后端不记账。
2. **key 走 `os.environ`**:`API_KEY = os.getenv("OPENROUTER_API_KEY")`——**代码里没有 key**,本地放 `.env`(已 gitignore),线上放平台 Variables。
3. **权限门的服务端版**:**去掉 `bash`**(公开服务绝不能让用户借 agent 执行系统命令!),只留白名单安全工具(样板里是 `save_journal`)。这就是 c5 权限门在服务端该有的样子。

还有两个"上线必备"的小东西,样板都有:
- **`/api/health`**:一个"我还活着"接口,部署平台用它做健康检查。
- **优雅降级 `FALLBACK`**:模型调不通时**返回一句兜底话,绝不 500 崩给用户**(`run_harness` 里 `if raw is None: return FALLBACK`)。这是小智 CompositeProvider 的思想。
- **CORS**:允许你的前端域名跨域访问(`CORSMiddleware`)。

> 安全一票否决怎么落地?看样板 `is_crisis()`:它在**入口**(收到消息先扫)和**出口**(`safety_review` 再扫)各拦一次危机——**确定性代码,不依赖模型**。离线不填 key,危机拦截照样生效。

## 操作步骤(对 Claude Code 说什么 + 你检查什么)

1. 说:"把我们的 harness 改成一个 FastAPI 服务:`POST /api/chat` 收 `{messages}`、跑一轮 harness、返回 `{reply, meta}`;`GET /api/health` 返回 ok。参照 `2_dev_deploy_guide/example_project/端到端示例_考前3分钟/backend/main.py`。"
2. 说:"key 从 `os.environ['OPENROUTER_API_KEY']` 读,写一个 `.env.example`,`.env` 加进 `.gitignore`。"
   - ✅ 你检查:`grep -rniE "sk-[a-z0-9]{16}" .` 在代码里**为零**。
3. 说:"去掉 bash 工具,只保留白名单安全工具;模型调不通时返回兜底话不要报 500;加 CORS。"
   - ✅ 你检查:本地起服务 `uvicorn main:app --port 8000`,`curl` 一下 `/api/health` 和 `/api/chat`(危机输入必转介)。
4. 填 `templates/API契约卡.md`:记下 `/api/chat` 的输入输出、要哪些环境变量。

## 痛点对比

| 😌 简单·看不出必要 | "我在终端里聊得好好的,干嘛还要包成接口?" |
|---|---|
| 🔥 复杂·痛点凸显 | 不服务化,前端就没法调、用户就用不上;若图省事把 key 塞前端直连模型,**一上线就被扒走盗刷,一夜账单爆炸**。服务化 + key 走后端,是唯一安全的姿势。 |
